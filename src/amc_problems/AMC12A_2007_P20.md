# Problem
Corners are sliced off a unit cube so that the six faces each become regular octagons.  What is the total volume of the removed tetrahedra?

answers = $\frac{5\sqrt{2}-7}{3}$, $\frac{10-7\sqrt{2}}{3}$, $\frac{3-2\sqrt{2}}{3}$, $\frac{8\sqrt{2}-11}{3}$, $\frac{6-4\sqrt{2}}{3}$


# Solution

Each face of the unit cube must become a regular octagon. Cutting a corner by distance $a$ along each edge replaces the square corner with a diagonal edge of length $a\sqrt{2}$, leaving a remaining side of $1 - 2a$. For a regular octagon these must be equal:

$$a\sqrt{2} = 1 - 2a \implies a(2 + \sqrt{2}) = 1 \implies a = \frac{1}{2+\sqrt{2}} = \frac{2-\sqrt{2}}{2}$$

Each of the 8 corners is cut off as a **right-corner tetrahedron** with three mutually perpendicular legs of length $a$. Its volume is $\tfrac{1}{6}a^3$, so the total removed volume is:

$$8 \cdot \frac{1}{6}a^3 = \frac{4}{3}a^3 = \frac{4}{3}\cdot\frac{(2-\sqrt{2})^3}{8}$$

Expanding $(2-\sqrt{2})^3 = 20 - 14\sqrt{2}$:

$$= \frac{4}{3}\cdot\frac{20-14\sqrt{2}}{8} = \frac{20-14\sqrt{2}}{6} = \boxed{\dfrac{10-7\sqrt{2}}{3}}$$

The answer is $\textbf{(B)}$.

// ---- Helper: make a corner tetrahedron mesh at corner (cx,cy,cz) ----
// with cut legs in directions dx,dy,dz (each ±1)
function makeCornerTet(cx, cy, cz, dx, dy, dz) {
  const geo = new THREE.BufferGeometry();
  // 4 vertices: corner + 3 cut points
  const pos = new Float32Array(4 * 3);
  const setV = (i, x, y, z) => { pos[i*3]=x; pos[i*3+1]=y; pos[i*3+2]=z; };
  // will be updated dynamically; init at a=0 (corner only)
  setV(0, cx, cy, cz);
  setV(1, cx, cy, cz);
  setV(2, cx, cy, cz);
  setV(3, cx, cy, cz);
  geo.setAttribute('position', new THREE.BufferAttribute(pos, 3));
  // 4 faces (outward winding from corner)
  geo.setIndex([
    0,1,2,  0,2,3,  0,3,1,  1,3,2
  ]);
  geo.computeVertexNormals();
  const mesh = new THREE.Mesh(geo, new THREE.MeshStandardMaterial({
    color: 0xff6644, transparent: true, opacity: 0.82,
    side: THREE.DoubleSide, roughness: 0.4, metalness: 0.1
  }));
  mesh._cx=cx; mesh._cy=cy; mesh._cz=cz;
  mesh._dx=dx; mesh._dy=dy; mesh._dz=dz;
  mesh._pos = pos;
  return mesh;
}

// 8 corners of the unit cube
