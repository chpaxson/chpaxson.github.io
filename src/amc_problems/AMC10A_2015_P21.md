# Problem
Tetrahedron $ABCD$ has $AB=5$, $AC=3$, $BC=4$, $BD=4$, $AD=3$, and $CD=\frac{12\sqrt{2}}{5}$.  What is the volume of the tetrahedron?

answers = $3\sqrt{2}$, $2\sqrt{5}$, $\frac{24}{5}$, $3\sqrt{3}$, $\frac{24\sqrt{2}}{5}$

# Solution

**Key observation:** Triangle $ABC$ has sides $AB=5$, $AC=3$, $BC=4$. Since $3^2+4^2=5^2$, it is a **right triangle with the right angle at $C$**. Likewise, triangle $ABD$ has the same three side lengths, so it is also right-angled at $D$.

**Coordinates.** Place $A=(0,0,0)$ and $B=(5,0,0)$. Put $C$ in the $xy$-plane: solving $AC=3$, $BC=4$ gives

$$C = \left(\frac{9}{5},\,\frac{12}{5},\,0\right).$$

$D$ shares the same $x$-coordinate by the same calculation: $D=\left(\frac{9}{5}, y_D, z_D\right)$ with $y_D^2+z_D^2 = \frac{144}{25}$. Now use $CD = \frac{12\sqrt{2}}{5}$:

$$CD^2 = \left(\frac{12}{5}-y_D\right)^2+z_D^2 = \frac{288}{25}-\frac{24y_D}{5}+\frac{144}{25} = \frac{288}{25}.$$

This gives $y_D = 0$, $z_D = \frac{12}{5}$, so $D = \left(\frac{9}{5},\,0,\,\frac{12}{5}\right)$.

**Volume.**

$$V = \frac{1}{6}\left|\det\begin{pmatrix}5&0&0\\9/5&12/5&0\\9/5&0&12/5\end{pmatrix}\right| = \frac{1}{6}\cdot 5\cdot\frac{144}{25} = \boxed{\dfrac{24}{5}}$$

The answer is $\textbf{(C)}$.
