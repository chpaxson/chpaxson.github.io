# Problem
A solid cube of side length 1 is removed from each corner of a solid cube of side length 3. How many edges does the 
remaining solid have?

answers = $84$, $12$, $36$, $60$, $20$

# Solution

Removing a 1×1×1 corner cube from the big cube creates **3 new square faces** (one cut into each of the 3 adjacent faces of the big cube). We count the edges of the final solid in three categories.

**Category 1 — Shortened original edges.** The big cube has 12 edges of length 3. Each edge has both endpoints at corners, so both ends are cut by 1 unit, leaving a segment of length 1 in the middle. This gives **12 edges**.

**Category 2 — Edges shared between an original face and a cut face.** Each original face of the big cube becomes a 12-sided rectilinear polygon (tracing the "plus-sign" shape left after removing four 1×1 corner squares from a 3×3 face gives 12 boundary segments). Of these 12 edges:
- 4 are the shortened original edges (Category 1, shared with adjacent faces)
- **8 are new edges** lying along cut faces

Total: $6\text{ faces} \times 8 = 48$ edges.

**Category 3 — Edges between two cut faces at the same corner.** The 3 cut faces at each corner meet pairwise, creating 3 new edges per corner:
$$8\text{ corners}\times 3 = 24\text{ edges}$$

**Total:**
$$12 + 48 + 24 = \boxed{84}$$

The answer is $\textbf{(A)}\ 84$.

// Build the CSG-like geometry using THREE.js
// We'll represent the solid as the big cube minus 8 corner pieces using a custom geometry.
// Strategy: use ConvexHull or manual face approach. Instead, let's build it from faces.

// The remaining solid has the following faces:
// 6 "original" faces: each is a 12-gon (3x3 square with 4 1x1 corners removed)
// 24 "cut" faces: 3 per corner × 8 corners, each a 1x1 square

const solidMat = new THREE.MeshStandardMaterial({
  color: 0x3355aa, roughness: 0.4, metalness: 0.1,
  transparent: true, opacity: 0.72, side: THREE.DoubleSide
});

// Helper: create a flat polygon geometry from a list of 2D points (in a specific 3D plane)
function makeFace(pts3d) {
  // pts3d: array of THREE.Vector3, convex or simple polygon
  // Triangulate as fan from first vertex
  const verts = [];
  for (let i = 1; i < pts3d.length - 1; i++) {
    verts.push(pts3d[0].x, pts3d[0].y, pts3d[0].z);
    verts.push(pts3d[i].x, pts3d[i].y, pts3d[i].z);
    verts.push(pts3d[i+1].x, pts3d[i+1].y, pts3d[i+1].z);
  }
  const geo = new THREE.BufferGeometry();
  geo.setAttribute('position', new THREE.BufferAttribute(new Float32Array(verts), 3));
  geo.computeVertexNormals();
  return geo;
}

// 12-gon profile for a 3x3 face with 1x1 corners removed (in 2D, then mapped to 3D)
// 2D coords (s=0..3): (1,0),(2,0),(2,1),(3,1),(3,2),(2,2),(2,3),(1,3),(1,2),(0,2),(0,1),(1,1)
// but we need to fan-triangulate a non-convex polygon
function make12gon(pts3d) {
  // Use centroid fan triangulation (works for star-shaped polygons)
  const cx = pts3d.reduce((s,p)=>s+p.x,0)/pts3d.length;
  const cy = pts3d.reduce((s,p)=>s+p.y,0)/pts3d.length;
  const cz = pts3d.reduce((s,p)=>s+p.z,0)/pts3d.length;
  const center = new THREE.Vector3(cx,cy,cz);
  const verts = [];
  for (let i = 0; i < pts3d.length; i++) {
    const a = pts3d[i], b = pts3d[(i+1)%pts3d.length];
    verts.push(center.x,center.y,center.z, a.x,a.y,a.z, b.x,b.y,b.z);
  }
  const geo = new THREE.BufferGeometry();
  geo.setAttribute('position', new THREE.BufferAttribute(new Float32Array(verts), 3));
  geo.computeVertexNormals();
  return geo;
}

// The 12 vertices of the plus-sign shape in (u,v) for a 3x3 face:
const profile2d = [
  [1,0],[2,0],[2,1],[3,1],[3,2],[2,2],[2,3],[1,3],[1,2],[0,2],[0,1],[1,1]
];

// 6 original faces — map (u,v) to 3D based on which face
const faces6 = [
  // z=0 face: u=x, v=y
  (u,v) => new THREE.Vector3(u, v, 0),
  // z=3 face: u=x, v=y
  (u,v) => new THREE.Vector3(u, v, 3),
  // x=0 face: u=z, v=y
  (u,v) => new THREE.Vector3(0, v, u),
  // x=3 face: u=z, v=y
  (u,v) => new THREE.Vector3(3, v, u),
  // y=0 face: u=x, v=z
  (u,v) => new THREE.Vector3(u, 0, v),
  // y=3 face: u=x, v=z
  (u,v) => new THREE.Vector3(u, 3, v),
];

faces6.forEach(mapFn => {
  const pts = profile2d.map(([u,v]) => mapFn(u,v));
  const geo = make12gon(pts);
  scene.add(new THREE.Mesh(geo, solidMat));

});

for (const cx of [0,3]) for (const cy of [0,3]) for (const cz of [0,3]) {
  const ix = cx===0 ? 1 : 2; // cut plane x
  const iy = cy===0 ? 1 : 2;
  const iz = cz===0 ? 1 : 2;
  const sx = cx===0 ? 1 : -1; // direction toward interior
  const sy = cy===0 ? 1 : -1;

  // x=ix cut face: square at {x=ix, y in [cy,cy+sy], z in [cz,cz+sz]}

  for (const pts of cutFaces) {

    const m = new THREE.Mesh(geo, cutMat);
    scene.add(m);
    cornerMeshes.push(m);

  addEdge(new THREE.Vector3(cx,cy,iz), new THREE.Vector3(cx,cy+sy,iz), 0x44ffaa); // on x=cx face
