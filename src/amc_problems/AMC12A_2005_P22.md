# Problem
A rectangular box $P$ is inscribed in a sphere of radius $r$. The surface area of $P$ is $384$, and the sum of the lengths of its 12 edges is $112$. What is $r$?

answers = $8$, $10$, $12$, $14$, $16$


# Solution
Let the box have dimensions $a$, $b$, $c$. From the given conditions:

$$2(ab + bc + ca) = 384 \implies ab + bc + ca = 192$$

$$4(a + b + c) = 112 \implies a + b + c = 28$$

Since the box is inscribed in the sphere, its space diagonal equals the diameter $2r$:

$$a^2 + b^2 + c^2 = (2r)^2$$

Using the identity $(a+b+c)^2 = a^2+b^2+c^2 + 2(ab+bc+ca)$:

$$28^2 = a^2+b^2+c^2 + 2(192) \implies a^2+b^2+c^2 = 784 - 384 = 400$$

Therefore $(2r)^2 = 400 \implies r = \boxed{10}$.

  const geo = new THREE.BufferGeometry();

function compute(a) {
  const S = 28 - a, P = 192 - a * S;
  const disc = S * S - 4 * P;
  if (disc < 0) return null;
  const sq = Math.sqrt(disc);
  const b = (S + sq) / 2, c = (S - sq) / 2;
  return (b > 0 && c > 0) ? { b, c } : null;
}
